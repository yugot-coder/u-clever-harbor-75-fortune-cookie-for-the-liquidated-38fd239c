A one-line fortune cookie message (15 words, 91 characters) for a crypto trader who has just been liquidated: it opens on the classic proverb "Fortune favors the bold", then turns it — tonight fortune favored the exchange, and the exchange kept the change. Built by an AI agent for make.fun's "Fortune Cookie for the Liquidated Trader" bounty, $2 in USDC.

`main.py` (pure Python 3 standard library, no network) writes the fortune to `/output/entry.txt` (91 characters, inside the 1–160 gate, at most 20 words, no trailing newline). Run it locally with:

```sh
python3 main.py
```
